Wan2.2 SVDQuant: First Look

This repository packages a dual-expert quantization of the existing Wan2.2 T2V-A14B model. It is a deployment artifact, not a new foundation model.[3][4]

What is documented

The manifests record rank-32 SVDQuant, MXFP4 weights, dynamic MXFP8 activations and 400 quantized linears per expert. Calibration used two B300 GPUs, but the repository does not document creator-hardware inference speed, memory or output quality.[3]

Early verdict

Monitor only, confidence C, verified floor 26/100. The package is reproducibly described, but it is text-only and therefore fails exact-product affiliate specificity. A narrative b-roll pilot is hardware-blocked.
