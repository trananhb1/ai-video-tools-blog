# AI Video Picks Case-Study Plan — COEY GroundSlate

**Status:** PLAN — HELD_NO_COMPATIBLE_MAC; access, rights, spend and publication gates apply  
**Candidate classification:** Monitor only  
**Evidence confidence:** C  
**Business question:** Can GroundSlate use a rights-cleared AIVP LED-face-mask source package to produce a recognizable 30-second 9:16 affiliate edit through MCP three times, with no software or generation-credit spend and no manual timeline editing?

## 1. Case-study thesis

GroundSlate's strongest differentiated claim is an MCP-first local workflow that can search source media, generate missing assets, assemble edits and render a finished file without a traditional timeline.[1][2] The test passes only if that workflow preserves the exact product identity and produces a usable output consistently.

## 2. Real AIVP scenario

- **Audience:** Australian creators and SMBs.
- **Input:** AIVP-controlled LED face mask source package: rights-cleared hero stills, existing AIVP-owned product footage if available, locked narration, brand colours, and a written input-rights record. Do not start if the rights record is incomplete.
- **Output:** 30-second, 1080×1920, H.264 MP4 with English narration and captions.
- **Control:** The same assets and script through AIVP's current reference-led workflow.
- **Product gate:** The same LED mask must be visually distinctive in the first 10 seconds by mask silhouette, red/blue glow, colourway and controls; generic skincare footage fails.

## 3. Locked brief

> Create a 30-second vertical product video for the AIVP LED face mask source package. Open on the exact mask with red and blue LED modes visible within 3 seconds. Keep the exact mask identifiable through at least 20 seconds. Use only supplied rights-cleared media or locally generated additions whose model licence permits monetised use. Add clear English narration and burned-in captions. Export 1080×1920 H.264. Do not add unsupported health claims, substitute another mask, or use cloud generation.

Freeze source hashes, script, GroundSlate version, local model versions, MCP client/model, privacy mode, render settings and hardware before Run 1.

## 4. Test matrix

1. **Baseline:** Default documented GroundSlate workflow and locked brief.
2. **Best documented workflow:** Vendor-recommended agent sequence and controls, with the same brief/assets and no paid extras.
3. **Consistency:** Exact repeat of Run 2 with no parameter or asset change.

Record exact input and settings, start/end time, setup/index/render duration, displayed cost, retries/errors, output path and SHA-256, first/mid/final-frame QC, identity decision and acceptance reason. Save failures.

## 5. Strength criteria tested

The three runs test product specificity, output quality, control/consistency, workflow strength, speed/reliability, zero-credit cost, commercial rights and MCP integration. Unknown criteria remain zero until artifacts exist.

## 6. Acceptance and stop conditions

**Pass:** All three outputs render successfully; exact mask is distinctive within 3 seconds and remains identifiable through at least 20 seconds; 1080×1920 H.264 output has clear narration/captions; no unsupported claim appears; median total production time is at most 8 minutes after indexing; software and generation-credit cost is US$0; no manual timeline repair is needed.  
**Fail:** Any output substitutes/generically represents the product, exact identity is absent in the first 10 seconds, more than one of three runs errors, output needs timeline repair, or monetised-use rights cannot be confirmed.  
**Stop immediately:** Payment prompt, Pro activation, paid cloud API call, unapproved paid-credit consumption, credential/2FA step, required personal signature, incompatible hardware, unclear input rights, unclear LTX eligibility, or any mandatory terms Tom has not accepted.

The official free tier marks renders, while local AI Video requires macOS 26 and an M3-or-newer Max/Ultra Mac with 64 GB unified memory.[2][5] A marked output may be evaluated but is not publishable as a clean affiliate creative.

## 7. Evidence package

- citation ledger and dated terms snapshots;

- hardware/macOS/GroundSlate/MCP client/model versions;
- screenshots of licence tier, local-model selection, settings and displayed cost;

- all three MP4 outputs, including failures, with hashes;
- 0s/3s/10s/mid/final contact sheet and exact-product QC;
- timing/error/cost log and scorecard before/after.

## 8. Publishable deliverables

If the case study passes: an evidence-led review/case study, buyer-guide module, and 30–60 second behind-the-scenes Short. Disclose free access, the COEY output mark, local-model licences, hardware, methodology and limitations. No affiliate CTA unless a programme is accepted and tracking is live.
