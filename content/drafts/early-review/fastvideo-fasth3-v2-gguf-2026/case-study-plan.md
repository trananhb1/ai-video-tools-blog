# AI Video Picks Case-Study Plan — FastH3 V2 GGUF

**Status:** PLAN — reference support, rights, security, hardware and spend gates apply  
**Candidate classification:** Monitor only  
**Evidence confidence:** C  
**Business question:** If FastH3 adds a compatible reference-conditioned checkpoint, can its Q4_K_M ComfyUI route create three repeatable 5-second vertical clips that preserve one exact rights-cleared LED mask at no cost and within two minutes per clip?

## 1. Case-study thesis

The conversion matters to AIVP only if the lower-storage local route preserves an exact affiliate product and yields usable synchronized video. Fast generic T2VA output is insufficient. The present checkpoint cannot answer this question because FL2VA and Ref2VA were not distilled.

## 2. Locked real-product brief

- **Audience:** Australian creators and SMB product marketers.
- **Input:** AIVP’s LED face-mask reference set only after the asset-rights record is re-confirmed; freeze all source hashes.
- **Prompt:** “Vertical close product demonstration of the referenced LED face mask on one person in a neutral bathroom; preserve shell shape, eye and mouth cut-outs, straps, controller and colourway; LEDs glow red; natural room sound; no text or added accessories.”
- **Output:** 5 seconds, closest supported 9:16 resolution at 24fps, H.264/AAC MP4.
- **Control:** identical source and prompt through Google Flow Veo 3.1 Fast References/Ingredients, with deterministic labels added only in post.
- **Hard product gate:** the exact mask must be visually distinctive in the first frame and throughout; generated footage is illustrative, not performance proof.

## 3. Three bounded runs

1. Baseline reference-conditioned settings and seed 41.
2. Best documented reference-conditioned settings and seed 42.
3. Exact repeat of run 2 with seed 42 to test reproducibility.

Record model/GGUF/supporting-file hashes, source/settings hashes, code commit and dependency lock, hardware/driver, commands, start/end/render time, energy or provider cost, output hash, errors and QC decision.

## 4. Pass/fail criteria

**PASS only if all three runs:** preserve the exact mask geometry, colour and controller; show it in the first second and sampled frames; deliver valid synchronized vertical MP4 at least 768×1344; complete in ≤120 seconds each; incur US$0/no paid credits; and satisfy monetized-publication terms.

**FAIL:** generic or altered mask, missing product within the first 10 seconds, audio/video desynchronization, invalid media, any failed/over-time run, non-zero unapproved cost or rights ambiguity.

**STOP immediately:** reference conditioning remains absent; security audit fails; hardware/provider requests payment; storage would breach the safe margin; password/2FA/identity/payment/signature is required; or input/output rights are unclear.

## 5. Evidence package

- frozen source assets and rights record;
- source commit, dependency lock and security-audit report;
- model/licence snapshots and every model hash;
- exact commands/settings and hardware telemetry;
- all three outputs, including failures, with SHA-256 hashes;
- first/middle/final-frame contact sheets and product-identity QC;
- decode/synchronization, timing, retry and cost logs;
- before/after scorecard and control delta.

## 6. Vendor-automation handoff

Before a run, audit ComfyUI-GGUF, every custom node, dependency lock, native kernel, download route, network egress and file sandbox. Keep auto-spend absent and outputs isolated. Do not add an API/MCP wrapper until one controlled no-cost run passes.

## 7. Publishable outputs if passed

Create an evidence-led case study, a local FastH3 comparison module and a behind-the-scenes Short. Include the AI-generated illustrative-demonstration disclosure. Add no affiliate CTA unless a programme is accepted and tracking is verified.

## 8. Decision

`RETEST` — wait for reference-conditioned V2 support and a no-cost compatible GPU route; the current T2VA-only artifact fails AIVP’s product gate by design.
