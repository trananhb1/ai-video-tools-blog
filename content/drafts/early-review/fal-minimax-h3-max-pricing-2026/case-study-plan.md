# Case Study Plan: fal MiniMax H3 Max Pricing and Product Fidelity

## Business question

Can fal H3 Max preserve the exact Revlon One-Step Volumiser Plus 2.0 identity in a 9:16 product-affiliate clip while keeping accepted-output cost at or below US$2 after the promotional pricing reset?

## Use case

Create one eight-second product-introduction anchor for the validated AIVP talking-UGC format. This is an AI-generated illustrative demonstration, not physical testing or performance proof.

## Locked brief

- Product: Revlon One-Step Volumiser Plus 2.0; use only AIVP rights-cleared source imagery.
- Input: same isolated front/three-quarter product reference and same locked prompt for all runs.
- Endpoint: H3 Max reference-to-video, 9:16/adaptive vertical, 768p, 8 seconds, identical settings.
- Prompt: show the black/red Revlon styling brush in hand, preserve barrel shape, bristles, red accents and control layout; one continuous waist-up bathroom demonstration; no text, no duplicate product, no unsupported performance claim.
- Output: MP4 suitable for deterministic post-production text and disclosure.
- Control: validated Google Flow Veo 3.1 Fast product-reference anchor.

## Success criteria

- Exact product is visually distinctive from frame one and throughout the first eight seconds.
- No material change to barrel geometry, colour blocking, bristle layout or controls.
- Hands are plausible and do not hide identifying details for more than two seconds.
- 9:16 framing is usable without reframing.
- No generated typography or unverified performance claim.
- Each accepted output costs no more than US$2.
- At least two of three identical runs pass all visual gates.

## Failure and stop conditions

- Product identity fails in run 1: continue only through run 2; stop if run 2 also fails.
- Forecast or quoted total exceeds the complimentary credit allowance or US$2 per run: stop before generation and ask Tom.
- Any card, payment, identity, password or 2FA step: pause for Tom.
- Commercial rights remain unresolved: outputs stay internal and unpublished.
- Two failed runs, unsafe content or unexpected billing: stop immediately.

## Three bounded runs

1. Run 1 — identical locked input, settings and seed policy.
2. Run 2 — exact repeat; no prompt repair.
3. Run 3 — exact repeat only if stop conditions remain clear.

## Evidence package

- Rights record and SHA-256 for every source asset.
- Exact endpoint/model identifier, API schema snapshot and normalized request JSON.
- Account quote showing effective unit price before each request.
- Request IDs, timestamps, queue/render duration, credits and charged amount.
- All three MP4 outputs including failures, SHA-256 hashes and mediainfo.
- First, midpoint and final frame captures with product-identity QC notes.
- ASR/transcript check if audio is generated.
- Commercial-rights response and disclosure requirement.
- Comparison against the existing Flow control for quality, time and accepted-output cost.

## Outcome

**Not started.** Blocked on complimentary access, effective-price verification and written commercial-use clarification. No paid credits were consumed.
