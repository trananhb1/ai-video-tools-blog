Wan2.2 W4A8 SVDQuant for NVIDIA: First Look

The Yi30 repository packages precomputed W4A8 SVDQuant artifacts for Wan2.2 TI2V-5B and T2V-A14B. It is a deployment optimization for existing Wan2.2 models, not a new foundation model.[1][2]

What is documented

The approximately 9.5GB 5B package supports the image-conditioned Wan2.2 route. Its sample setting is 480×832, 41 frames and 20 steps, with a publisher-reported 26.3GB peak memory. The approximately 54GB A14B package has a publisher-reported 56.4GB peak.[1]

Why AIVP has not tested it

The current host has no detected NVIDIA GPU and cannot run the measured memory envelope. No paid cloud compute or hardware purchase is authorized.

Early verdict

Monitor only, confidence C, verified floor 32/100. Apache-2.0 licensing, image conditioning and packaged command-line setup are documented, but output quality, reliability, accepted-output cost and exact-product preservation are unverified.[1][2]

This is not a product-affiliate recommendation. The LED mask identity must remain distinctive across three saved runs before that gate can open.
