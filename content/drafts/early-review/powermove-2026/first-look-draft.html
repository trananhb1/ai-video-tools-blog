Powermove v1.0.0 First Look: An Open-Source, Self-Rewriting Motion Editor for macOS

Released on September 18, 2026, Powermove v1.0.0 introduces an unconventional take on AI video and motion editing.[9] Developed by iterative-computer as free software under GPL-3.0, Powermove embeds a coding agent directly inside the editor's operational loop.[5][10]

An Extensible, Agent-Operated Architecture

Unlike conventional video editors that graft a sidecar chatbot onto a legacy codebase, Powermove keeps its core engine intentionally minimal.[5] Features such as the timeline, inspectors, keyframing panels, and effects are built as modular extensions. Users describe desired modifications in natural language; the embedded agent (powered by a local, authenticated session of OpenAI Codex or Anthropic Claude Code) renders frames to inspect project state, formulates transactional edits via typed APIs, and updates the running interface in place.[5][10]

Runtime Prerequisites and Limitations

Powermove targets technical creators and developers: it requires macOS running on Apple Silicon, Bun 1.3+, and existing developer accounts for Claude Code or Codex.[5] Because the host evaluation environment is Linux x86_64, controlled execution is held under standing policy until Apple Silicon test hardware is allocated.
