## Critical Finding: Math Error in Rejected PRs

PRs #40, #42, #43 each added the following to `posts/grok-imagine-video-review-2026.html`:

> "API costs **$0.05/sec ($4.20/min with audio)**"

**$0.05 × 60 = $3.00/min, not $4.20/min.** This is a factual inaccuracy that would mislead readers about Grok's API pricing. The correct price (confirmed in PR #44) is **$4.20/min = $0.07/sec**.

PR #41 avoided this error by only stating "$4.20/min (with audio)" without the per-second breakdown.
PR #44 correctly states "$4.20/min at 720p ($0.07/sec)" in the update callout.
