## CI Fix Applied — Weekly Newsletter Workflow

**Problem:** GitHub Actions `send-newsletter` job has been failing (run a0bafe5, 2026-05-08 23:57 UTC, 7 seconds).

**Root cause:** The workflow only passed `RESEND_API_KEY` and `RESEND_AUDIENCE_ID` to the Python script. The script's default send mode (`personalized`) calls the Cloudflare Worker at `aivideopicks-newsletter.trananhb1.workers.dev` and authenticates with `ADMIN_TOKEN`. Since `ADMIN_TOKEN` was not set, it defaulted to an empty string → Worker rejected the request.

**Fix applied:** Updated `.github/workflows/weekly-newsletter.yml` to also pass:
- `ADMIN_TOKEN: ${{ secrets.NEWSLETTER_ADMIN_TOKEN }}`
- `WORKER_URL: ${{ secrets.NEWSLETTER_WORKER_URL }}`

**CEO action required — BLOCKING:** The GitHub secrets `NEWSLETTER_ADMIN_TOKEN` and `NEWSLETTER_WORKER_URL` must be added in GitHub repo settings → Settings → Secrets and variables → Actions:
- `NEWSLETTER_ADMIN_TOKEN` = the `ADMIN_TOKEN` value set via `wrangler secret put ADMIN_TOKEN` on the Worker
- `NEWSLETTER_WORKER_URL` = `https://aivideopicks-newsletter.trananhb1.workers.dev` (or leave blank to use the default hardcoded in the script)

Without these secrets, the newsletter will continue failing every Saturday at 9 AM AEST.
